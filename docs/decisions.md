# Decisions

One log of the decisions that still shape the project: what was decided, when, and why. Newest at
the bottom. The full discussion of each, with the options that were turned down, is in the
milestone's file in `docs/history/` (decision IDs like `10b-2` point there).

**When to add a row:** whenever a choice is made that a later session could reasonably undo
without knowing why — a product rule, an architecture boundary, a tool turned down, an accepted
limit. Add it in the same commit as the change. A decision that is reversed gets a new row; the
old one stays.
